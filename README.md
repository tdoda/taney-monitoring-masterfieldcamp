# Taney_Monitoring_MasterFieldCamp

Monitoring of Lake Taney by the Aquatic Science Master students of the University of Lausanne.

Online repository: https://github.com/tdoda/taney-monitoring-masterfieldcamp.git 

## Introduction

This project aims to study the thermal structure of Lake Taney (Valais, Switzerland) and its fluctuations in relation to significant water level variability.  The data were collected as part of the Master's Field Camp in Aquatic Science at the University of Lausanne from 4 to 6 June 2025 and are being used to analyse the physical and biogeochemical dynamics of the lake.

## Github repository structure:


The repository is organised so as to separate raw data, processing scripts and analysis notebooks.

### Data
Contains the various datasets collected in the field, organised by type:

- **`Meteo/`** → meteorological data (air temperature, wind, radiation, etc.)
- **`Mooring/`** → data from sensors installed on the lake mooring
- **`Profiles/`** → spot measurements of vertical profiles (temperature, oxygen, conductivity, etc.)

Notes:

The files corresponding to the periods studied are in ‘yearmonthday’ format, e.g. 20250603.
The ‘EXO_...’ probes are to be disregarded. Only use the RBR probes. 
The ‘HOBO_P’ file (pressure sensor) is empty. Disregard.

Each type of data is processed through several levels of pre-processing:

| Level | Description | Example |  

| **Level 0** | Raw data, `.csv` files exported from the logger |

| **Level 1** | Cleaned data and file converted to NetCDF file (“.nc”: used to store multidimensional data) |

| **Level 2** | Calibrated and merged data, ready for analysis (addition of metadata, time alignment, hourly/daily averages)|

(| **Level 3** *(optional)* | Interpreted or aggregated data for final analyses |)

### Notebook
Contains the Jupyter notebooks used for:
- **visualising results** (`plot_ctd.ipynb and 'plot_mooring.ipynb`)
- a “Figures” folder: for storing figures automatically generated by the notebooks.  

Each notebook is self-contained and documented so that it can be easily reused by students or researchers involved in monitoring.
